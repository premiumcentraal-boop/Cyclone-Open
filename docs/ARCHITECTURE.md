# Architecture
Host APK `com.cyclone.open` is standalone; min Android 13. Quick Settings tile is an owner-added shortcut, not an always-running background service. Android user settings and Home are native system actions. The app stores drafts and document references in an atomic, app-private registry. Registry selection is NOT a device switch. 
Next: runtime capability probe, typed start/stop/attach interface, operation journal with generation IDs, explicit target handshake, recovery to host. A future privileged runtime must be an independently reviewed narrow owner-controlled service, not unrestricted shell execution. Host owns the registry; guest companions use authenticated session-scoped requests. Guest image boot must require authentic manifest, compatible architecture/runtime, immutable verified image and independent disk. Imported document digest alone is insufficient.
Native user bridge: opt-in on supported firmware; no root operations implemented now. Companion availability across users is a future acceptance requirement, not a current claim.
